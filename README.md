# FiveM Admin Menu

A comprehensive admin menu system for FiveM servers with essential admin tools.

## Features

- Comprehensive admin menu with multiple features
- User-friendly interface for administrators
- Essential admin tools for managing players

## Requirements

- FiveM server
- ESX Framework
- RageUI library

## Installation

1. Download the latest release from the [releases page](https://github.com/EnderDevelopment/fivem-admin-menu/releases).
2. Extract the contents of the zip file into your FiveM server's `resources` directory.
3. Add `start fivem-admin-menu` to your `server.cfg` file.

## Usage

1. Connect to your FiveM server.
2. Type `/admin` in the chat to open the admin menu.
3. Use the menu to manage players.

## Configuration

The plugin can be configured by editing the `config.lua` file. The following options are available:

- `MenuTitle`: The title of the admin menu.
- `MenuSubtitle`: The subtitle of the admin menu.
- `MenuColor`: The color of the admin menu.
- `AdminGroups`: The groups that have access to the admin menu.
